## 1️⃣ B.Tech CSE — Core Program

### Program Details

| Field | Information |
|---|---|
| **Full Name** | B.Tech in Computer Science and Engineering |
| **Degree** | Bachelor of Technology |
| **Duration** | 4 Years / 8 Semesters |
| **Campus** | Dehradun (also Haldwani) |
| **Eligibility** | 12th PCM from recognized board |
| **Admission** | JEE Main / GECET / Merit (12th %) |
| **Department** | School of Engineering and Technology |

### Core Subjects

- Programming Fundamentals (C, C++, Java, Python)
- Data Structures & Algorithms
- Computer Organization & Architecture
- Operating Systems
- Computer Networks
- Database Management Systems
- Software Engineering
- Theory of Computation
- Compiler Design
- Discrete Mathematics
- Digital Logic Design
- Web Technologies
- Artificial Intelligence (introductory)
- Cloud Computing (elective)

### Learning Outcomes

1. Design and implement algorithms for computational problems
2. Develop software systems using best engineering practices
3. Understand computer hardware-software interaction
4. Apply databases and networking concepts in real systems
5. Work in team environments using Agile/DevOps methodologies
6. Communicate effectively and demonstrate professional ethics
